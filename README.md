# Vivekanand Portfolio

Premium recruiter-focused portfolio website for Vivekanand Amol Chougule.

## Structure

```text
Vivekanand-Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
├── .gitignore
└── assets/
    ├── resume.pdf
    └── images/
```

## Run locally

Open `index.html` directly in a browser, or serve the folder with a simple static server.

## Resume file

The portfolio expects the resume at:

```text
assets/resume.pdf
```

Replace that file with the latest version while keeping the same name so all resume buttons continue to work.

## Notes

- Built with HTML5, CSS3, and Vanilla JavaScript
- Responsive for desktop, tablet, and mobile
- Uses a premium dark AI/developer visual system
- Content matches the provided resume and project links
